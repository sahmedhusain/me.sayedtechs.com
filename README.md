# Interactive Resume - Sayed Ahmed Husain

A modern, responsive, and interactive resume built with HTML, CSS, and JavaScript featuring Material 3 Design System, smooth animations, and dynamic content.

## 🚀 Features

- **Material 3 Design System** with light/dark theme support
- **Responsive Design** that works on all devices
- **Interactive Timeline Graph** showing career journey
- **Animated Background** with particle effects
- **Smooth Animations** using Anime.js
- **Card Tilt Effects** for enhanced interactivity
- **Dynamic Content Injection** via JavaScript
- **QR Code Resume Download** modal
- **Professional Sections**: Experience, Skills, Projects, Education, Certifications

## 📁 Project Structure

```
resume/
├── index.html          # Main HTML structure
├── style.css           # All CSS styles and animations
├── main.js            # JavaScript functionality and interactions
└── README.md          # Project documentation
```

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Custom properties, animations, and responsive design

## 🚀 Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. The resume will load with all interactive features

No build process or dependencies required - it's a static website that runs directly in the browser.

## 📱 Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge

## 🔧 Customization

### Updating Content
Edit the data arrays in `main.js`:
- `experienceData` - Work experience
- `internshipData` - Internship details
- `skillsData` - Technical and soft skills
- `projectsData` - Projects and portfolio items
- `educationData` - Educational background
- `certsData` - Certifications and licenses

### Styling
Modify `style.css` to:
- Change color scheme
- Adjust animations
- Update layout and spacing
- Customize component styles

### Functionality
Update `main.js` to:
- Add new interactive features
- Modify animations
- Change behavior of existing components
